# Talent Scout Hub

Crie um aplicativo que possa ser utilizado tanto no celular, quanto no computador para avaliar atletas de base de futebol das categorias do Sub-11 ao Sub-20. Utilize as métricas da imagem anexada para criar os critérios a serem analisados, bem como utilize inteligência artificial para obter informações sobre os aspectos técnicos e táticos que os observadores técnicos buscam nos atletas. O layout do aplicativo deverá ter a aparência de um campo de futebol com as posições de cada jogador que farão a avaliação. Quando preenchido a posição aparecerá a foto e o nome do atleta avaliado. Quando clicado sobre a foto deverá ser ativada uma sub-tela de opções com dois botões: um para acesso aos detalhes do atleta para ser preenchido com os dados (Nome completo, data de nascimento, pé dominante, posição, altura e peso) e outro para avaliação do atleta escolhido com os dados da imagem: técnica individual (controle, passe, finalização, condução e jogo aéreo); tática/leitura de jogo (posicionamento, corredores, impedimento e transição); física (velocidade, agilidade e resistência aeróbia específica do futebol; Mental/comportamental (concentração, decisão sob pressão e atitude).
